# 전자정부 프레임워크 lab301-mvc 기반 검토

### 빌드
1. mvn clean
2. mvn install

### 실행
실행 환경이 설정 안 된 경우, Edit Configurations... 메뉴 선택
1. \+ 클릭
2. Tomcat Server > Local 선택
3. JRE: 1.8 선택
4. Deployment 탭 이동
5. \+ 클릭
6. Artifact... 선택
7. lab301-mvc-tutor:war 선택, OK 클릭
8. Run 버튼 클릭

### 화면 접근
1. 인텔리제이로 실행한 경우: http://localhost:8080/lab301_mvc_tutor_war/

### Swagger
http://localhost:8080/lab301_mvc_tutor_war/swagger-ui/index.html
